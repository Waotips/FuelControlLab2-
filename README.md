# ЛР 2. Работа с географическими информационными системами

## Вариант
**El Camino de Santiago + Система контроля топлива**.

Приложение написано на **Java** для **Android Studio**. Карта реализована через **OpenStreetMap/osmdroid**, поэтому ключ Google Maps API не нужен.

## Что сделано строго по методичке

### 1. Отображение карты
- Используется `org.osmdroid.views.MapView`.
- Источник тайлов: `TileSourceFactory.MAPNIK`, то есть OpenStreetMap.
- На карте показан маршрут **El Camino de Santiago**.

### 2. Отслеживание местоположения
- Приложение запрашивает разрешения `ACCESS_FINE_LOCATION` и `ACCESS_COARSE_LOCATION`.
- Координаты берутся через `LocationManager` по GPS и сети.
- На карте отображается маркер текущего местоположения пользователя.

### 3. Построение маршрута
- На карте отмечены старт и финиш:
  - старт: **Саррия**;
  - финиш: **Сантьяго-де-Компостела**.
- Маршрут построен синей линией по ключевым точкам Camino: Sarria, Portomarín, Palas de Rei, Melide, Arzúa, O Pedrouzo, Santiago de Compostela.

### 4. Логирование пути
- Кнопка **«Начать трек»** включает запись фактического пути.
- Фактический путь пользователя отображается красной линией.
- Трек сохраняется в `SharedPreferences` и восстанавливается после перезапуска приложения.
- Кнопка **«Очистить трек»** удаляет записанный путь.

### 5. Расчет статистики
- Рассчитывается длина маршрута Camino.
- Рассчитывается пройденное расстояние по фактическому треку.
- Рассчитывается средняя скорость.

### 6. Вариант: система контроля топлива
- Пользователь вводит:
  - расход автомобиля, л/100 км;
  - остаток топлива в баке;
  - цену за литр;
  - количество литров для дозаправки.
- Приложение рассчитывает:
  - расход топлива по пройденному пути;
  - стоимость израсходованного топлива;
  - остаток топлива;
  - запас хода;
  - сколько топлива нужно до финиша;
  - сколько топлива и денег нужно на весь маршрут.
- При нехватке топлива приложение показывает предупреждение, Toast, вибрацию и системное уведомление.

## Как запустить

1. Распаковать архив.
2. Открыть папку `FuelControlLab2` в Android Studio через `File -> Open`.
3. Дождаться Gradle Sync.
4. Запустить приложение на телефоне или эмуляторе с включенной геолокацией.
5. Разрешить доступ к геолокации и уведомлениям.

## Проверка без реального перемещения

Для проверки на эмуляторе есть кнопка **«Точка Camino»**. Она последовательно добавляет контрольные точки маршрута в трек, пересчитывает расстояние, среднюю скорость и расход топлива.

## Основные файлы

- `app/src/main/java/com/example/fuelcontrollab2/MainActivity.java` — логика карты, GPS, трека, статистики и контроля топлива.
- `app/src/main/res/layout/activity_main.xml` — интерфейс приложения.
- `app/src/main/AndroidManifest.xml` — разрешения и главная Activity.
